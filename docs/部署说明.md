# 部署说明

## 1. 本地开发部署

### 1.1 安装环境

确认 Node.js 版本：

```bash
node --version
```

必须为 22.5.0 或更高，因为后端使用 Node 原生 SQLite。

### 1.2 安装依赖和配置

```bash
npm install
cp .env.example .env
npm run db:setup
```

Windows PowerShell 复制命令：

```powershell
Copy-Item .env.example .env
```

### 1.3 启动

终端1：

```bash
npm run server
```

终端2：

```bash
npm run dev
```

访问 `http://localhost:5173`。检查 `http://localhost:3001/api/health` 应返回 `status: ok`。

## 2. 真实 AI 配置

编辑 `.env`：

```dotenv
LLM_MODE=api
LLM_API_URL=https://你的模型服务/v1/chat/completions
LLM_API_KEY=真实密钥
LLM_MODEL=模型名称
LLM_TIMEOUT_MS=30000
```

重启后端后配置才会生效。不要把 `.env` 发给组员或提交到版本库；共享 `.env.example` 即可。

如果演示现场网络不稳定，把 `LLM_MODE` 改回 `mock`，核心人工确认和数据库流程不变。

## 3. 单机生产部署

### 3.1 生产配置

```dotenv
PORT=3001
TASKFLOW_DB_PATH=./data/taskflow.sqlite
TOKEN_TTL_HOURS=24
FRONTEND_ORIGIN=https://你的域名
AUTO_SEED_DEMO=false
LLM_MODE=api
LLM_API_URL=https://你的模型服务/v1/chat/completions
LLM_API_KEY=真实密钥
LLM_MODEL=模型名称
LLM_TIMEOUT_MS=30000
```

如果课程演示仍需预置账号，可在首次启动时保留 `AUTO_SEED_DEMO=true`，确认数据生成后再改为 `false`。

### 3.2 构建并启动

```bash
npm install
npm run db:migrate
npm run build
npm run server
```

当 `dist/index.html` 存在时，Node 后端会自动托管前端页面和 SPA 路由。浏览器访问 `http://服务器地址:3001` 即可，不需要另开 Vite 开发服务器。

### 3.3 进程守护

可用操作系统服务或团队熟悉的进程管理器守护 `node server/index.js`。至少应做到：程序异常退出后自动重启、保存标准输出、启动时加载项目目录下的 `.env`。

### 3.4 反向代理与 HTTPS

公网部署时建议由 Nginx、Caddy 或云平台反向代理把 HTTPS 请求转发到 `127.0.0.1:3001`。后端端口不直接暴露公网，并将 `FRONTEND_ORIGIN` 设置为实际 HTTPS 域名。

## 4. 数据库迁移与备份

每次更新代码后先备份，再运行：

```bash
npm run db:migrate
```

SQLite 使用 WAL 模式。可靠备份应在服务停止后复制以下数据库文件，或使用 SQLite 官方备份命令：

- `data/taskflow.sqlite`
- 同目录可能存在的 `taskflow.sqlite-wal`
- 同目录可能存在的 `taskflow.sqlite-shm`

恢复时停止服务，把同一批备份文件放回原位置，再启动服务。不要只复制正在写入中的主数据库文件。

## 5. 上线前检查

```bash
npm run test:backend
npm run build
```

然后按顺序手工检查：

1. 组长登录并保存会议；
2. AI 生成草稿；
3. 不明确负责人不能直接确认；
4. 修正并确认后进入看板；
5. 组员只能更新自己的任务；
6. 教师账号不能写入；
7. 修改状态后统计同步变化；
8. `.env`、数据库文件和 API Key 未进入前端 `dist`。

## 6. 常见问题

### `node:sqlite` 不存在

Node.js 版本过低。升级至 22.5 或更高，不要额外安装来源不明的 SQLite 包。

### 前端提示 `Failed to fetch`

确认后端已运行在 3001 端口；开发环境确认 Vite 由项目根目录启动；检查 `vite.config.js` 的 `/api` 代理。

### 返回 401

token 缺失、无效或已过期。退出后重新登录；不要手工拼接旧 token。

### 返回 403

这是角色、团队或资源归属校验失败。用组长账号确认草稿；组员只能修改自己任务；教师为只读。

### AI 返回 502/503

检查 `LLM_MODE`、API URL、密钥、模型名和网络；先切换 `LLM_MODE=mock` 判断业务系统本身是否正常。服务端不会把上游密钥或完整敏感错误返回浏览器。

### 草稿无法确认

负责人、截止日期或原文依据至少有一项不合法。先在 AI 草稿页修正并保存；原文依据必须是会议纪要中的连续文本。

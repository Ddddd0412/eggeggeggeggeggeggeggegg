## 三、协作流程

1. 王毅博确定需求、AI输入输出格式和异常处理规则，并维护AI API相关实现。

## 六、提交前检查

1. 确认 `.env` 未加入Git，代码、截图、文档和PPT中没有真实API密钥。
2. 执行 `npm install`、`npm run db:setup`、`npm run test:backend` 和 `npm run build`。
3. 启动前后端，使用组长、组员和教师账号分别检查权限。
4. 按“会议录入—AI提取—人工修改—确认任务—看板—统计”的顺序完成浏览器验收。
5. 准备一段短会议录音和一份会议纪要文本；真实转写服务异常时使用文本继续演示核心流程。
6. 按教师指定的文件名、压缩格式和邮箱要求提交，发送后保留邮件与附件截图。

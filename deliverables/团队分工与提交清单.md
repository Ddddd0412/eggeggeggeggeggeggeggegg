# 团队分工与提交清单

## 一、团队分工（提交前补齐姓名）

| 角色 | 成员姓名 | 主要交付 |
| --- | --- | --- |
| 产品与提示词负责人 | 待补 | 真实需求、会议任务字段、提示词规则、边界样例 |
| 前端交互负责人 | 待补 | 登录、会议录入、录音上传、草稿确认、任务看板 |
| 后端与数据库负责人 | 待补 | REST API、鉴权、SQLite、事务、统计与审计 |
| 集成测试与答辩负责人 | 待补 | 真实录音联调、自动化测试、演示流程、答辩材料 |

> 一人可承担多个角色，但答辩时每位成员都要说清个人贡献、关键判断和验证证据。

## 三、答辩前 10 分钟检查

1. `.env` 已配置但未加入 Git，密钥未出现在截图或 PPT。
2. `npm test` 显示 `15 passed / 0 failed`。
3. `npm run build` 成功，浏览器可打开登录页。
4. 准备一段 20—40 秒、无长静音的会议录音和一份文本兜底。
5. 登录后依次演示：会议录入 → AI提取 → 修改草稿 → 确认 → 看板 → 统计。
6. 准备回答：为什么必须人工确认、如何处理模糊日期、如何避免密钥泄露。
